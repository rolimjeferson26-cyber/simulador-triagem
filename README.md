# Simulador de Triagem → agora no Prontidão

**Este projeto continua em [prontidao.pt](https://prontidao.pt/simulador/).**

O Simulador de Triagem foi integrado no **Prontidão**, a app de formação em emergência pré-hospitalar que junta o Simulador de Triagem, a Avaliação ABCDE, os Parâmetros vitais, as Consultas de bolso e a Anatomia interativa.

## Formadores: exporta os teus casos antes de mudar

Os casos de treino que criaste no simulador antigo estão guardados **no teu browser** e não passam sozinhos para o site novo.

1. Abre o endereço antigo **no mesmo browser onde criaste os casos**: https://rolimjeferson26-cyber.github.io/simulador-triagem/
2. Carrega em **«Exportar os meus casos»**. O ficheiro `casos_ficticios_custom.json` fica só no teu computador; nada é enviado para lado nenhum.
3. No Prontidão, abre o **Formador** e usa **«Importar»**.
